# AutoCode 2FA

Support, privacy policy and security design for AutoCode 2FA, a Windows two-factor (TOTP) authenticator.

- Support / FAQ: https://ft94.github.io/autocode-2fa-site/
- Privacy policy: https://ft94.github.io/autocode-2fa-site/privacy-policy.html
- Security design: https://ft94.github.io/autocode-2fa-site/security.html

Questions and bug reports: open an issue in this repository. Never post 2FA keys, passwords or recovery codes.
